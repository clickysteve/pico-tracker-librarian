Live mirror of the picoTracker screen over USB (Remote UI protocol), drawn with the device's own font. Stock firmware is view-only — the experimental input mode speaks a proposed key-event opcode that needs firmware support. Requires Chrome/Edge (WebSerial) and Remote UI set to On in the device config.
The output effects run on the GPU and are applied to the mirror only — nothing is ever sent to the device. Pop the mirror out into its own window and capture that window in OBS (or any screen recorder) to record it — and for Syphon workflows on macOS, feed that captured window out through a Syphon server (OBS has community server plugins; window-to-Syphon utilities work too — the browser itself cannot publish Syphon). The screen above is a stand-in until a device is connected, so a look can be dialled in ahead of time.
